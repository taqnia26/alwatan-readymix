TOOL: Replit — السبب: موقع تعريفي فيه CMS كامل (تحكم بكل نص/زر/محتوى)، نموذج طلب عرض سعر بالبريد، وداشبورد إدارية احترافية — هذا يحتاج Backend حقيقي (قاعدة بيانات + مصادقة + معالجة نماذج)، وهو بالضبط مجال قوة Replit.

[1] PROJECT OVERVIEW
اسم المشروع: شركة الوطن للخرسانة الجاهزة | AlWatan Ready-Mix Company
النشاط: مصنع خرسانة جاهزة بثلاثة فروع في الرياض
الهدف: موقع تعريفي فاخر بالهوية البصرية الرسمية، فيه طلب عرض سعر يصل بالإيميل، وداشبورد إدارية بها CMS كامل — أي نص أو زر أو مقالة بالموقع قابل للتعديل من الداشبورد بدون لمس الكود
الجمهور: أفراد ومقاولون وشركات إنشاءات وجهات حكومية بحاجة لخرسانة جاهزة
الدومين: www.alwatan2030.com
اللغات: العربية (الأساس) + الإنجليزية مع دعم RTL/LTR كامل
[2] TECH STACK
Frontend:
- React + Vite
- Tailwind CSS + shadcn/ui
- Framer Motion للأنيميشن
- Lucide React للأيقونات
- react-i18next للترجمة (AR/EN)
- TipTap أو React-Quill (محرر نصوص غني للمقالات داخل الداشبورد)

Backend:
- Node.js + Express
- PostgreSQL (database: alwatan_db)
- Drizzle ORM
- JWT للمصادقة (Admin فقط — لا حسابات عملاء بهذا المشروع)
- Nodemailer (إرسال نموذج طلب عرض السعر كإيميل مباشر)
- Multer / Cloudinary (رفع صور الشعارات، الشهادات، صور المقالات، صور الفروع)

Hosting: Replit Deployments
[3] PAGES & ROUTES
الواجهة العامة
/                       → Home (Hero + عن الشركة مختصر + المنتجات + الفروع + الشهادات + CTA طلب عرض سعر)
/about                  → من نحن (الرؤية، الرسالة، القيم — محتوى من البروفايل)
/products               → قائمة أنواع الخرسانة الجاهزة
/products/[slug]        → تفاصيل نوع خرسانة محدد (المواصفات، الاستخدامات، القوة الانضغاطية)
/branches               → الفروع الثلاثة (حي النظيم، ملهم، الفرسان) + خريطة Google Maps لكل فرع
/certificates           → صفحة الشهادات والاعتمادات (SASO وغيرها) بعرض بصري احترافي
/quote                  → نموذج طلب عرض سعر (متعدد الخطوات: نوع المنتج → الكمية → الموقع → معلومات التواصل)
/blog                   → المدونة/الأخبار (تُدار بالكامل من الداشبورد)
/blog/[slug]            → مقالة محددة
/contact                → تواصل + واتساب + نموذج + خريطة الفروع
الداشبورد الإدارية (محمية — /admin)
/admin                  → Overview (عدد طلبات عروض الأسعار الجديدة، زيارات، آخر المقالات)
/admin/quotes           → إدارة طلبات عروض الأسعار الواردة (حالة: جديد/تم التواصل/مغلق)
/admin/content          → CMS: تعديل كل نص وزر بكل صفحة عامة (Home, About, Contact, إلخ) — لا حاجة لإعادة نشر الكود
/admin/products         → إضافة/تعديل/حذف أنواع الخرسانة ومواصفاتها
/admin/branches         → إدارة بيانات الفروع الثلاثة (العنوان، الإحداثيات، ساعات العمل، الهاتف)
/admin/certificates     → رفع/تعديل/حذف شهادات واعتمادات (صور + وصف)
/admin/blog             → إدارة المقالات (محرر نصوص غني + صور + نشر/مسودة)
/admin/media            → مكتبة وسائط مركزية (كل الصور المرفوعة بمكان واحد)
/admin/settings         → إعدادات عامة (رقم واتساب، إيميل استقبال طلبات العروض، روابط سوشيال ميديا)
/admin/users            → إدارة حسابات الداشبورد (لو أكثر من موظف يدخل)

[5] COMPONENTS & UI ELEMENTS
Navbar: Sticky، شفاف على Hero ثم Solid عند Scroll. الشعار + قائمة + Language Toggle + زر "اطلب عرض سعر" بارز بالأخضر
Hero: خلفية صورة/فيديو لمصنع خرسانة حقيقي + عنوان قوي + إحصائيات (سنوات خبرة، عدد المشاريع، ٣ فروع) + زرّي CTA (اطلب عرض سعر / تعرف على منتجاتنا)
Product Cards: بطاقة لكل نوع خرسانة (صورة + اسم + مواصفة مختصرة + زر "التفاصيل")
Trust Badges Strip: شريط أفقي بشعارات الشهادات (SASO وغيرها) بجودة عالية، بيانات كل شهادة تُدار من /admin/certificates
Branch Cards: بطاقة لكل فرع (اسم، عنوان، ساعات عمل، رقم مباشر) + خريطة مصغّرة، تفتح خريطة كاملة عند الضغط
Quote Request Wizard: نموذج متعدد الخطوات (Progress bar): ١) نوع الخرسانة ٢) الكمية التقريبية والموقع ٣) معلومات التواصل (اسم، جوال، إيميل) ٤) تأكيد وإرسال — عند الإرسال يذهب كإيميل فوري لصندوق الشركة + يُحفظ بـ /admin/quotes
Stats Counter: عداد Count-up عند دخول الـ Viewport
Blog Cards: صورة + عنوان + مقتطف + تاريخ
Rich Text Renderer: لعرض محتوى المقالات المُدارة من محرر TipTap بالداشبورد بتنسيق سليم (عناوين، صور، قوائم)
Footer: ٤ أعمدة (روابط سريعة / المنتجات / الفروع / تواصل) + أيقونات سوشيال ميديا + حقوق النشر

[8] INTEGRATIONS
Email: Nodemailer + SMTP (أو Resend/SendGrid) — إرسال فوري لكل طلب عرض سعر جديد لصندوق بريد الشركة المحدد بـ /admin/settings

WhatsApp: زر Float ثابت + رابط wa.me — الرقم يُدخَل من /admin/settings
(الرقم غير مؤكد لدي حالياً — اجعله حقل قابل للتعديل من الداشبورد فور التسليم، لا تكتبه Hardcoded بالكود)

Maps: Google Maps Embed API لكل فرع من الفروع الثلاثة (حي النظيم، ملهم، الفرسان)

Analytics: Google Analytics 4
[9] ADMIN DASHBOARD — تفاصيل الـ CMS الكامل

هذا القسم هو جوهر المشروع — الداشبورد ليست "إدارة بيانات" فقط بل محرر مباشر لكل عنصر بالموقع:

محرر المحتوى المرئي (/admin/content): لكل صفحة عامة (Home, About, Contact...) قائمة بكل Section فيها — كل عنوان، فقرة نص، ونص زر قابل للتعديل مباشرة عبر نموذج، مع معاينة فورية (Preview) قبل النشر
إدارة الأزرار والـ CTA: نص كل زر + الرابط الذي يوجه إليه قابلان للتعديل من الداشبورد (لا نص Hardcoded بالكود لأي CTA)
دور واحد بالبداية: Admin كامل الصلاحيات (يمكن توسيعه لأدوار متعددة لاحقاً مثل موظف تسويق يدير المقالات فقط)
سجل تعديلات (Audit Log) بسيط: من عدّل أي نص ومتى — لحماية المحتوى من تعديلات غير مقصودة

[11] AUTHENTICATION & SECURITY
Auth: Email + Password للداشبورد فقط (لا حسابات عملاء بهذا المشروع)
JWT: Access (15 دقيقة) + Refresh (٧ أيام)
Rate Limiting: 5 محاولات دخول/دقيقة
CSRF Protection على كل POST/PUT/DELETE بالداشبورد
Password Policy: 8+ أحرف، حروف كبيرة وصغيرة، رقم، رمز خاص
Validation صارم على نموذج طلب عرض السعر (منع Spam bots — reCAPTCHA v3 أو honeypot field)

Meta tags ديناميكية (عربي + إنجليزي) لكل صفحة، قابلة للتعديل من /admin/content

Sitemap.xml تلقائي (يتحدث تلقائياً عند إضافة مقالة أو منتج جديد)
Hreflang tags للصفحات الثنائية اللغة
Image optimization (WebP + Lazy Load) — مهم جداً لصور المصنع والمنتجات الثقيلة
Lighthouse target: 90+
